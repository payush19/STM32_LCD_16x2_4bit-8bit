# STM32 LCD 16x2 Interfacing (4-bit Mode)

## Overview
This project demonstrates interfacing a 16x2 LCD with STM32F446RE in 4-bit mode  and 8-bit mode using Embedded C.

## Features
- LCD Initialization
- Character Display
- String Display
- Cursor Position Control
- 4-bit Data Communication
- 8-bit Data Communication

## Hardware Used
- STM32F446RE Nucleo Board
- 16x2 LCD
- Breadboard
- Jumper Wires
- potentiometer for LCD brightness

## Software Used
- STM32CubeIDE
- Embedded C

## Project Objective
To understand GPIO interfacing and LCD communication using 4-bit mode and 8-bit mode for efficient pin utilization.

## Result
Successfully displayed characters and strings on a 16x2 LCD using STM32.
